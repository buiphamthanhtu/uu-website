Dành cho AI

Tài liệu ở dạng máy đọc, cùng nội dung với Storybook. AI coding agent đọc theo thứ tự trong llms.txt.

  • llms.txt — mục lục và sáu ràng buộc
  • design-system.md — spec đầy đủ
  • tokens.css — CSS custom properties
  • tokens.json — token cho iOS, Android, Flutter
  • icons.md — luật dùng UU icon
