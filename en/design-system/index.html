Token architecture

Base color → role → component

Components may only name roles. Hex values sit at the bottom layer, untouched by any component.

Layer 1 · primitive 211 base colors · 19 ramps × 11 steps
Layer 2 · semantic 57 tokens named by role · brands change only this layer
background-interactive object-primary background-positive border-interactive
Layer 3 · component 48 components read roles only and work in every brand
Send Cancel Final
Brand modeDefault · UU — switched with data-theme
DensityTouch for apps · Compact for desktop
LayoutExpanded · collapsed for side navigation
UnitsWeb uses rem to scale with the user's font size · apps use px
